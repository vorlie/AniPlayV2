Provider-aware by design

One interface.
Independent catalogs.

Providers are kept separate, with honest capability differences and visible fallbacks. AniPlay never hosts the media it discovers.

Local where it matters

Your viewing setup is yours.

AniPlay is explicit about what stays local and which services a feature contacts. It does not operate a hidden media backend.

01

Local history

Resume state, viewing events, preferences, and achievements stay in app data.

02

Encrypted sign-in

AniList authentication uses Electron secure storage when the platform provides it.

03

Isolated providers

Provider sessions, headers, and fallbacks are scoped rather than applied globally.

04

Opt-in torrents

Peer-to-peer playback starts only after consent and exposes its network implications.
